<a id="overview"></a>

**Homicipher: Prologue** is an adventure game developed by Yatsunagi that offers a unique twist in gameplay: players must decipher an unknown language to progress through an immersive story. Fully localized in Japanese, English, Simplified Chinese, and Traditional Chinese, this game invites players to navigate a richly crafted world with a gameplay time of approximately 15-20 minutes. In this latest version, players assume the role of a girl trapped in the Other World, encountering mysterious characters that speak an unfamiliar language.
